# O que a Ocupacional 3D precisa enviar

O site já está no ar com espaços marcados ("Foto em breve", "Primeiro vídeo em breve"). Nada foi inventado: não há depoimentos, clientes, preços ou números fictícios. Esta é a lista do que falta para completar.

## 1. Imagens

| Item | Formato ideal | Onde entra |
|---|---|---|
| **Logo em SVG** (versão colorida e versão para fundo escuro) | SVG vetorial | Cabeçalho, rodapé, favicon e imagem de compartilhamento. Hoje é uma logo provisória em texto. |
| **Fotos dos Kits O3D** (1 principal + extras, se quiserem) | JPG/PNG, mínimo 1600 px de largura, horizontal 4:3 | Cartão "Kits O3D" |
| **Fotos de dispositivos personalizados** (de preferência sendo usados por uma pessoa, com autorização de imagem) | Idem | Cartão "Dispositivos personalizados" |
| **Foto da Roberta** e **foto da Clarissa** | Vertical 4:5, mínimo 1000 px de altura | "Quem somos" |
| Logos de clínicas parceiras (se quiserem mostrar, com autorização) | SVG ou PNG transparente | "Clientes e depoimentos" |

**Para cada foto, mandem uma frase dizendo o que aparece nela e para que serve o dispositivo.** Ela vira o texto alternativo, lido em voz alta para pessoas cegas. Exemplo: "Mão segurando um garfo com cabo engrossado azul, impresso em 3D, para quem tem pouca força para fechar a mão."

Eu converto as fotos para WebP, ajusto o tamanho e coloco carregamento sob demanda.

## 2. Textos para confirmar

Escrevi estes textos a partir do briefing. **Confirmem ou corrijam:**

- [ ] **Kits O3D:** "Conjuntos de dispositivos para atividades do dia a dia, como comer, escrever e cuidar de si." Os kits são mesmo para essas atividades? Quais kits existem e o que vem em cada um?
- [ ] **Indicado para:** as listas dos dois cartões ("Quem está começando a usar tecnologia assistiva", "Pessoas com alterações de força, movimento ou coordenação" etc.).
- [ ] **Prazo:** "Entrega em 3 a 7 dias úteis". O prazo inclui o frete para outros estados ou é só a produção?
- [ ] **Como usar:** "Vídeos curtos vão mostrar como colocar, ajustar e cuidar de cada dispositivo." Esse é o plano para os vídeos?
- [ ] **Trilha da Inovação:** "Uma trilha de formação sobre tecnologia assistiva e impressão 3D, do raciocínio clínico à peça pronta." Para quem é, qual o formato (on-line/presencial), carga horária e se há certificado.
- [ ] **Capacitações para equipes:** "Encontros sob medida para clínicas, instituições de ensino e equipes de reabilitação."
- [ ] **Missão:** "criar tecnologia assistiva que se adapta à pessoa, e não o contrário." É assim que vocês descrevem a missão?
- [ ] **Perguntas frequentes:** "Peça um orçamento pelo WhatsApp: é rápido e sem compromisso." O orçamento é mesmo sem compromisso? Há outras perguntas que as pessoas fazem com frequência?

## 3. Depoimentos

Somente depoimentos **reais**, com **autorização por escrito** (uma mensagem no WhatsApp dizendo "autorizo" já serve). Para cada um:
- o texto do depoimento, nas palavras da pessoa;
- nome como ela quer aparecer (pode ser só o primeiro nome) e cidade;
- relação: usuária, mãe, cuidadora, terapeuta…

O espaço já está pronto e aceita quantos depoimentos vocês tiverem.

## 5. Vídeos tutoriais

Para cada vídeo:
- o arquivo de vídeo (MP4, horizontal);
- **legendas** em português (arquivo `.vtt`). Se não tiverem, eu gero um rascunho para vocês revisarem;
- uma **transcrição** em texto, descrevendo também o que aparece na tela ("ela encaixa o adaptador no cabo da colher").

## 6. Para o futuro: loja online

A seção de produtos já está estruturada para virar loja. Cada produto é um bloco com dados de produto (schema.org) e um espaço de preço oculto. Quando quiserem vender pelo site, será preciso:
- lista de produtos com nome, descrição, preço e fotos;
- a plataforma de pagamento escolhida (ex.: Mercado Pago, Stripe, PagSeguro).
